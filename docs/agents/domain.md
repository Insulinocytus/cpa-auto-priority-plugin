# Domain Docs

## 布局

采用 single-context：术语表位于根目录 `GLOSSARY.md`，架构决策记录位于 `docs/adr/`。

## 探索代码前

- 读取根目录 `GLOSSARY.md`。
- 读取 `docs/adr/` 中与当前工作相关的 ADR。
- 文件不存在时静默继续，不因缺失而预先创建或建议创建。
  `/domain-modeling` 在实际确定术语或决策后按需创建这些文档。

## 术语和决策

- 工单标题、重构提案、假设和测试名称使用术语表定义的词汇，避免其明确排除的同义词。
- 所需概念未在术语表中定义时，先检查是否引入了项目未使用的语言；确有缺口则记录供 `/domain-modeling` 处理。
- 提案与现有 ADR 冲突时，明确指出冲突的 ADR 和重新讨论的理由。
