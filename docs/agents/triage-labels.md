# Triage Labels

规范角色与本仓库实际标签的映射：

| 规范角色 | 实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 等待维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可由无人值守 agent 实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不予处理 |

技能提到规范角色时，使用表中对应的实际标签。
调整现有标签命名时，只修改“实际标签”列。
